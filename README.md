# Hukum Singh Rathore — Personal Portfolio

A responsive portfolio website built with React and Vite. Includes About, Skills, Projects, Education/Experience, CGPA, and Contact sections.

## Run locally

1. Open this folder in VS Code.
2. Open **Terminal → New Terminal**.
3. Run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Important customizations before submission

- Update the placeholder email `your.email@example.com`.
- Replace the generic GitHub and LinkedIn URLs with your own profile links.
- Replace sample project cards and links with projects you have actually built.
- Confirm that the name, degree, university, CGPA, and internship information are accurate.

## Production build

```bash
npm run build
```

The generated site will be placed in the `dist` folder.
